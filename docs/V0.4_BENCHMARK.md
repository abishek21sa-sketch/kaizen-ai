# V0.4.1 Blind Statistical-Investigator Benchmark

## Purpose

Validate that the Statistical Investigator can distinguish the six modeled Hidden Factory incident families **without receiving scenario code or sealed causal truth as an input**, and that it identifies the modeled affected target and direction rather than merely the mechanism family.

## Matrix

Seeds: `3, 7, 17, 42, 113, 2718`  
Scenarios per seed: 6  
Total blind incidents: **36**  
Units per incident: **900**

## Scoring dimensions

1. Top-1 mechanism family
2. Mechanism + affected target/asset
3. Full attribution: mechanism + target + direction + interaction partner

Expected target examples include M2 for tool calibration drift, G2 for measurement drift, F4 for fixture/environment interaction, an S2 lot for the supplier/humidity case, Calibration for intermittent capacity loss, and Calibration product transitions for changeover deterioration.

## Result

- Top-1 mechanism-family accuracy: **36/36 (100%)**
- Mechanism + affected-target accuracy: **36/36 (100%)**
- Full attribution accuracy: **36/36 (100%)**

## Important limitation

These numbers describe only the current deterministic synthetic Hidden Factory benchmark. They are **not** an estimate of performance on an unseen real manufacturing system. The benchmark is useful because the simulator supplies sealed ground truth for validation after inference; it does not prove external validity.

V0.4.1 specifically strengthens the benchmark after acceptance testing exposed a two-level DID labeling error where the mechanism family was correct but the unaffected complement asset could be named.
